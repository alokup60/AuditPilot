# AuditPilot

AuditPilot is an AI-powered website audit and redesign proposal platform.

It crawls a target website, collects evidence, performs deterministic analysis, generates AI-assisted recommendations and redesign strategy, and produces a client-ready proposal.

## Repository foundation

- `apps/web` — React + TypeScript + Vite frontend
- `apps/api` — Node.js + Express + TypeScript API
- `apps/workers` — background processing workers
- `packages/*` — shared contracts, domain, validation, errors, security, observability, configuration, and utilities
- `docs` — implementation documentation and status
- `infrastructure` — deployment/infrastructure notes
- `tests` — cross-application test assets
